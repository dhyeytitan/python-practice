# python-practice

A beginner-friendly Python practice repository.

## Goal
Start learning Python from scratch with small hands-on exercises.

## Getting started
1. Make sure Python 3 is installed:
   ```bash
   python3 --version
   ```
2. Run your first practice script:
   ```bash
   python3 practice/01_basics.py
   ```

## Practice roadmap
- Day 1: print, variables, input/output
- Day 2: data types and operators
- Day 3: conditionals (`if/elif/else`)
- Day 4: loops (`for`, `while`)
- Day 5: functions
- Day 6: lists, tuples, dictionaries, sets
- Day 7: mini project

Keep adding one small script per topic in the `practice/` folder.
